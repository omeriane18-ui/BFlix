# BFlix 🎬

موقع كتالوج أفلام ومسلسلات بواجهة عربية RTL، داكنة افتراضيًا مع وضع فاتح، وبحث وتصنيفات وتقييمات ومفضلة ولوحة تحكم كاملة.

## ✨ المميزات

- صفحة رئيسية بتصميم عصري مع إحصائيات مباشرة وعمل مميّز.
- مكتبة موحّدة بفلاتر: الكل / أفلام / مسلسلات / المفضلة.
- فلترة حسب التصنيف (تُبنى تلقائيًا من بياناتك) + ترتيب (الأحدث، الأعلى تقييمًا، السنة، أبجديًا).
- بحث فوري بالاسم/التصنيف/الوصف.
- صفحة تفاصيل لكل عمل مع تقييم، وسوم، زر مفضلة، زر مشاركة الرابط، وأعمال مشابهة بنفس التصنيف.
- قائمة مفضلة شخصية لكل زائر (تُحفظ في متصفحه).
- وضع داكن/فاتح مع حفظ التفضيل.
- قائمة جوال (Hamburger menu) للشاشات الصغيرة.
- لوحة تحكم كاملة (`admin.html`) خلف شاشة دخول:
  - إضافة/تعديل/حذف الأعمال.
  - تصدير البيانات كملف JSON واستيرادها.
  - استعادة البيانات التجريبية الأصلية بضغطة واحدة.
  - تغيير كلمة مرور اللوحة.
- صفحة 404 مخصصة، و`robots.txt`، و`manifest.json`.
- متجاوب بالكامل مع الجوال والتابلت والكمبيوتر.
- لا حاجة لأي أدوات بناء (Build tools) — HTML/CSS/JS خام تمامًا.

## 🚀 النشر على GitHub Pages (خطوة بخطوة)

### الطريقة 1: عبر واجهة GitHub مباشرة (الأسهل)

1. اذهب إلى [github.com](https://github.com) وسجّل الدخول.
2. اضغط **New repository**، واختر اسمًا (مثلاً `bflix`)، واجعله **Public**، ثم **Create repository**.
3. في صفحة المستودع الجديد اضغط **uploading an existing file**.
4. اسحب/ارفع **جميع ملفات هذه الحزمة** (بما فيها `.nojekyll` الملف المخفي — إن لم يظهر عند السحب، ارفعه يدويًا أو استخدم الطريقة 2 عبر Git).
5. اضغط **Commit changes**.
6. من تبويب **Settings → Pages**:
   - تحت **Source** اختر **Deploy from a branch**.
   - اختر الفرع `main` والمجلد `/ (root)`.
   - اضغط **Save**.
7. انتظر دقيقة أو دقيقتين، وسيظهر رابط الموقع أعلى الصفحة بصيغة:
   `https://<username>.github.io/<repo-name>/`

### الطريقة 2: عبر سطر الأوامر (Git)

```bash
cd bflix          # المجلد الذي يحوي ملفات المشروع
git init
git add .
git commit -m "BFlix: نسخة أولى جاهزة للنشر"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

ثم فعّل GitHub Pages من **Settings → Pages** كما في الخطوة 6 أعلاه.

> ⚠️ ملف `.nojekyll` مهم لأنه يمنع GitHub من معالجة الموقع كموقع Jekyll، ما يضمن تحميل كل الملفات كما هي.

## 🔐 لوحة التحكم

- الرابط: `admin.html`
- كلمة المرور الافتراضية: **`bflix2026`**
- يمكنك تغييرها من داخل اللوحة عبر زر **"تغيير كلمة المرور"**.

### البيانات مشتركة عبر السحابة

البيانات محفوظة في حاوية JSONBin واحدة يقرأ منها كل الزوّار، لا في متصفح كل جهاز. ما تضيفه من اللوحة يظهر للجميع فورًا.

- القراءة للزوّار تتم بلا أي مفتاح (الحاوية Public)، فلا يوجد سر داخل ملفات المستودع.
- الكتابة تحتاج مفتاحًا تُدخله مرة واحدة في **إعدادات السحابة** داخل اللوحة، ويُحفظ في متصفحك وحدك.
- إذا فشل الرفع إلى السحابة، لا يُطبَّق التغيير محليًا وتظهر لك رسالة الخطأ — لن تظن أن شيئًا حُفظ وهو لم يُحفظ.
- `localStorage` صار نسخة عرض احتياطية عند انقطاع الإنترنت فقط.

راجع **`CLOUD-SETUP.md`** لخطوات الإعداد الكاملة.

### ما يزال ناقصًا

شاشة الدخول في `admin.html` حماية شكلية: كلمة المرور مكتوبة في المتصفح ويمكن تجاوزها من أدوات المطوّر. مفتاح الكتابة هو الحاجز الفعلي الوحيد. للحصول على مصادقة حقيقية، انتقل لاحقًا إلى Supabase (قاعدة بيانات + تسجيل دخول + صلاحيات على مستوى الصف).

## 🧩 إضافة/تعديل المحتوى

الطريقة الأسهل: من لوحة التحكم مباشرة (`admin.html`).

بديل تقني: عدّل مصفوفة `SEED_ITEMS` في أعلى ملف `app.js` مباشرة، ثم من لوحة التحكم اضغط **"استعادة البيانات التجريبية"** لتحميل القيم الجديدة (ملاحظة: هذا يستبدل أي تعديلات محلية سابقة).

كل عمل له الحقول التالية:

| الحقل | الوصف |
|---|---|
| `id` | معرّف فريد (يُنشأ تلقائيًا عند الإضافة من اللوحة) |
| `type` | `movie` أو `series` |
| `title` | اسم العمل |
| `year` | سنة الإصدار |
| `genre` | تصنيفات مفصولة بفواصل، مثل: `دراما، أكشن` |
| `rating` | تقييم من 10 (اختياري) |
| `description` | وصف العمل |
| `image` | رابط صورة البوستر |
| `watchUrl` | رابط مشاهدة خارجي |
| `featured` | `true`/`false` — هل يظهر كعمل مميز في الرئيسية |
| `addedAt` | تاريخ الإضافة (يُستخدم للترتيب حسب "الأحدث") |

> 🖼️ صور المشروع الحالية (في البيانات التجريبية) هي صور عامة من خدمة placeholder (`picsum.photos`) لأغراض العرض فقط — استبدلها بروابط صور بوسترات حقيقية تملك حقوقها أو حق استخدامها.

## ⚖️ ملاحظة قانونية

هذا الموقع **كتالوج معلومات وروابط خارجية فقط** — لا يستضيف أو يوزّع أي ملفات فيديو أو محتوى محمي بحقوق النشر. تأكد أن روابط "المشاهدة" التي تضيفها تشير إلى مصادر قانونية مرخّصة، وأن الصور المستخدمة (بوسترات، صور مصغّرة) لديك الحق في استخدامها أو نشرها.
